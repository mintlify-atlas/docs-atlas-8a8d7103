<Note>
  You need a **WhatsApp Business account** and a Meta developer app to receive and send messages through the WhatsApp Business API. If you haven't set that up yet, follow the [WhatsApp setup guide](/guides/whatsapp-setup) first.
</Note>

## Prerequisites

Before you start, make sure you have the following:

| Requirement | Details |
|---|---|
| Python 3.8+ | [python.org/downloads](https://www.python.org/downloads/) |
| pip | Bundled with Python 3.4+ |
| Groq API key | Free at [console.groq.com](https://console.groq.com) |
| ngrok | [ngrok.com/download](https://ngrok.com/download) — exposes your local server to the internet so the WhatsApp webhook can reach it |
| WhatsApp Business account | Required to configure a webhook and send/receive messages |

## Setup

<Steps>

  <Step title="Clone the repository">
    ```bash
    git clone https://github.com/juliorbk/yoko.git
    cd yoko
    ```
  </Step>

  <Step title="Install dependencies">
    Yoko requires only two packages: `flask` for the webhook server and `requests` for HTTP calls to the Groq API and WhatsApp Business API.

    <CodeGroup>

    ```bash pip
    pip install flask requests
    ```

    ```bash pip3
    pip3 install flask requests
    ```

    </CodeGroup>
  </Step>

  <Step title="Create your knowledge base">
    Yoko answers questions by fuzzy-matching incoming messages against a local `data.json` file. Create this file in the project root:

    ```json data.json
    [
      {
        "pregunta": "¿Cuándo es el período de inscripciones?",
        "respuesta": "El período de inscripciones para el semestre 2025-1 es del 10 al 20 de enero de 2025."
      },
      {
        "pregunta": "¿Cuál es el horario de la biblioteca?",
        "respuesta": "La biblioteca universitaria está abierta de lunes a viernes de 7:00 a.m. a 9:00 p.m., y los sábados de 8:00 a.m. a 2:00 p.m."
      },
      {
        "pregunta": "¿Dónde queda la oficina de registro?",
        "respuesta": "La oficina de registro académico se encuentra en el edificio administrativo, planta baja, ventanilla 3."
      }
    ]
    ```

    Each object requires a `pregunta` (the question used for matching) and a `respuesta` (the context passed to the LLM). Add as many pairs as your use case needs.

    <Tip>
      The fuzzy matcher in `mcp.py` uses a similarity cutoff of `0.4`. Write questions in the same natural phrasing your users are likely to send.
    </Tip>
  </Step>

  <Step title="Set your environment variables">
    Open `llm.py` and replace the empty string with your Groq API key:

    ```python llm.py
    GROQ_API_KEY = "gsk_your_key_here"  # your Groq API key
    GROQ_MODEL = "llama3-8b-8192"
    ```

    Open `app.py` and set `VERIFY_TOKEN` to any string you choose — you will use this same value when registering the webhook in the Meta dashboard:

    ```python app.py
    VERIFY_TOKEN = "my-secret-token"  # match this in your WhatsApp webhook config
    ```

    <Warning>
      Do not commit your `GROQ_API_KEY` to version control. Consider moving secrets to a `.env` file and loading them with `python-dotenv` before deploying.
    </Warning>
  </Step>

  <Step title="Run the Flask server">
    ```bash
    python app.py
    ```

    You should see output similar to:

    ```
     * Running on http://127.0.0.1:5000
     * Debug mode: on
    ```

    The server listens on port `5000` by default. Leave this terminal open.
  </Step>

  <Step title="Expose your local server with ngrok">
    Open a new terminal and run:

    ```bash
    ngrok http 5000
    ```

    ngrok will print a public HTTPS URL, for example:

    ```
    Forwarding  https://a1b2-203-0-113-1.ngrok-free.app -> http://localhost:5000
    ```

    Copy the `https://` URL — you'll need it in the next step.

    <Note>
      Free ngrok URLs change every time you restart ngrok. You'll need to update the webhook URL in the Meta dashboard each time. For a permanent URL, use a paid ngrok plan or deploy to a cloud server.
    </Note>
  </Step>

  <Step title="Configure the WhatsApp webhook">
    In your [Meta for Developers](https://developers.facebook.com/) app:

    1. Go to **WhatsApp** → **Configuration** → **Webhook**.
    2. Set the **Callback URL** to your ngrok URL followed by `/webhook`:
       ```
       https://a1b2-203-0-113-1.ngrok-free.app/webhook
       ```
    3. Set the **Verify token** to the same value you put in `VERIFY_TOKEN` inside `app.py`.
    4. Click **Verify and save**.
    5. Subscribe to the **messages** webhook field.

    Meta will send a `GET /webhook` request with a challenge to verify ownership. Yoko responds automatically when the token matches.

    <Warning>
      The `enviar_mensaje` function in `app.py` also requires a valid WhatsApp Business API URL and a Bearer token to send replies. Set these before testing end-to-end message delivery. See the [WhatsApp setup guide](/guides/whatsapp-setup) for details.
    </Warning>
  </Step>

</Steps>

---

## Test it

Send a WhatsApp message to your business phone number. If everything is configured correctly:

1. WhatsApp delivers the message to `POST /webhook`.
2. `mcp.py` fuzzy-matches it against `data.json` and returns the closest answer as context.
3. `llm.py` sends the context and question to Groq (LLaMA 3 8B).
4. `app.py` sends the generated reply back to your WhatsApp number.
