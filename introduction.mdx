## What is Yoko?

Yoko is a lightweight WhatsApp chatbot server that connects the **WhatsApp Business API** to a **Groq-powered LLM** (LLaMA 3 8B). When a user sends a WhatsApp message, Yoko:

1. Receives the message through a Flask webhook
2. Searches a local JSON knowledge base for relevant context using fuzzy matching
3. Sends the user's question plus the matched context to the Groq LLM
4. Returns the AI-generated response back to the user via WhatsApp

It was designed as a university assistant chatbot but can be adapted to any domain by swapping the knowledge base.

## Key features

<CardGroup cols={2}>
  <Card title="WhatsApp webhook" icon="comment-dots">
    Receives and verifies WhatsApp Business API webhook events via a Flask HTTP server.
  </Card>
  <Card title="Fuzzy knowledge base" icon="magnifying-glass">
    Matches incoming questions against a JSON knowledge base using Python's `difflib` for context-aware retrieval.
  </Card>
  <Card title="Groq LLM integration" icon="robot">
    Queries the Groq API with LLaMA 3 (8B) using the matched context to generate accurate, grounded responses.
  </Card>
  <Card title="Easy to self-host" icon="server">
    A minimal Python/Flask stack with no database required — just a JSON file and environment variables.
  </Card>
</CardGroup>

## How it works

```
User (WhatsApp)
      │
      ▼
POST /webhook  (Flask · app.py)
      │
      ▼
buscar_contexto()  (mcp.py)
  → fuzzy match against data.json
      │
      ▼
consultar_llm()  (llm.py)
  → Groq API / LLaMA 3 8B
      │
      ▼
enviar_mensaje()  (app.py)
  → WhatsApp Business API
      │
      ▼
User receives reply
```

## Project structure

| File | Purpose |
|------|---------|
| `app.py` | Flask app, webhook handler, and WhatsApp message sender |
| `mcp.py` | Context retrieval via fuzzy matching against `data.json` |
| `llm.py` | Groq API client for LLaMA 3 inference |
| `data.json` | Your knowledge base — question/answer pairs |
| `print.py` | Utility script to simulate webhook delivery events |
